# Naga Venkata Sai Manikanta Srighakollapu - Personal Portfolio

A state-of-the-art, interactive portfolio web application showcasing **Naga Venkata Sai Manikanta Srighakollapu**'s technical background, competitive coding profiles, AI & Prompt Engineering certifications, ServiceNow & AWS projects, and career achievements.

## 🌟 Key Features

- **Dark & Light Mode Support**: Persistent theme switching with CSS variables and smooth transitions.
- **Coding Profiles Spotlight**: Dedicated highlight cards for **LeetCode** (`saimanikantacm104`), **CodeChef** (`manikanta103`), **GitHub** (`manikanta1203`), and **LinkedIn** with problem solver stats.
- **AI & Certifications Showcase**: Features 16 verified certifications including IBM Prompt Engineering, Generative AI & Agents, Gemini Certified Faculty, Claude AI Fluency, AWS Certified AI Practitioner, ServiceNow CSA & CAD, Snowflake, Oracle, Postman, HackerRank, and CodeChef.
- **Interactive Certificate Modal Viewer**: Click any certification card to open a modal window displaying verified skills, issuer metadata, and direct PDF document / preview image viewer.
- **Projects Showcase**: Filterable project cards with live application links (*T@G Digital Pulse* at `tag.ncet.co.in`), AWS live streaming infrastructure, IoT assistive hardware, and ServiceNow apps.
- **Career & Education Timeline**: Interactive vertical timeline covering Torii Minds, Technical Hub, AWS DevOps, Aditya University (M.Tech CSE 9.0 CGPA), Aditya College of Engineering (B.Tech IT 8.52 GPA), and Polytechnic Diploma.
- **Direct Resume Downloads**: Embedded access to both latest and previous resume PDFs.

## 🚀 How to View Locally

Simply double-click `index.html` or open it in any web browser (Chrome, Edge, Firefox, Brave, Safari).

Alternatively, launch a simple HTTP server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js npx
npx http-server -p 8000
```
Then visit `http://localhost:8000` in your web browser!
